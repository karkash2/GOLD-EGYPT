ذهب مصر – الإصدار الأول
========================
المشروع يتضمن:
- تطبيق Android يعرض صفحة أسعار eDahab المنشورة على Ta3weem داخل التطبيق.
- Widget أسود وذهبي يفتح صفحة الأسعار عند الضغط عليه.
- GitHub Actions لبناء APK تلقائياً.

مهم بخصوص مصدر البيانات:
حتى الآن لم يتم التحقق من وجود API عامة ومصرح باستخدامها لبيانات eDahab عبر Ta3weem.
لذلك لا يعرض هذا الإصدار أرقاماً منسوخة أو قديمة داخل الـ Widget ولا يدّعي أنها أسعار لحظية.
التطبيق يفتح صفحة المصدر الأصلية لعرض الأسعار ووقت آخر تحديث كما يظهران لدى المصدر.
بعد الحصول على API أو إذن استخدام البيانات، يمكن تطوير الـ Widget ليعرض أسعار 24/21/18/14 مباشرة مع توقيت التحديث.

البناء:
ارفع محتويات هذا المجلد إلى مستودع GitHub على الفرع main.
سيبدأ GitHub Actions تلقائياً، ثم حمّل Artifact باسم Gold-Egypt-APK.
